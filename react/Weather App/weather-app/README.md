# Weather App

This small project helped me become more familiar with React. 
My goal with this project was to further deepen my understanding of the basics, including fundamental hooks, handling REST API requests, and conditional rendering.
Even though the design for this project is only functional and there is much room for improvement, it was interesting to create dynamic styles using React. 
For example, changing the icon depending on the temperature or creating a menu subitem for the hourly weather data.

For this project, I used the free API from https://www.weatherapi.com/ for the weather data.
To host the project locally, you need to register and obtain an API key.
This must then be stored with the URL in an .env file as "VITE_API_KEY" and "VITE_API_URL".
